## 2025-05-18 - Zero-Copy Single-Pass G-Code Parsing Overhead on Microcontrollers
**Learning:** Standard C library routines (`isspace`, `toupper`, `strchr`, `strtof`, `atoi`) introduce noticeable overhead on microcontroller stream processing (e.g. ESP32 Core 0 handling UART baud streams) due to intermediate buffer copies, multiple string traversals per axis token, and locale/exponent handling in `strtof`. Replacing this with an inline zero-copy single-pass scanner using custom ASCII branchless character transforms and numeric conversions provides a ~9x parsing throughput improvement while conserving stack memory.
**Action:** In high-frequency command streaming paths on embedded systems, parse numeric tokens in a single forward pass without intermediate line cleaning buffers or multiple `strchr` scans.
