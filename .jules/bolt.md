## 2025-08-11 - [Low-Level Direct Register Writes in High-Frequency Stepper ISR]
**Learning:** Standard ESP-IDF `gpio_set_level()` introduces significant function call, validation, and locking overhead that can consume excessive CPU cycles and cause timing jitter or CPU starvation when invoked inside a 100kHz timer ISR. Direct hardware register writes via memory-mapped registers (`GPIO_OUT_W1TS_REG`/`GPIO_OUT_W1TC_REG` and `GPIO_OUT1_W1TS_REG`/`GPIO_OUT1_W1TC_REG`) allow changing pin states in a few CPU cycles. Furthermore, precalculating the exact register addresses and bitmasks during initialization completely eliminates any runtime branching inside the ISR.
**Action:** Always precalculate and cache the hardware register pointer and bitmask for critical, high-frequency IO operations at initialization time to avoid `gpio_set_level()` overhead and branching inside performance-critical paths/ISRs.
